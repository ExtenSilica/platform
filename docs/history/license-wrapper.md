# License wrapper (historical)

Runtime **commercial license** enforcement in bitstreams was part of an older product model. **ExtenSilica does not use pay-per-flash, license tokens, or payment-gated execution.** See [pivot-v2.md](./pivot-v2.md).

Technical integrity (hashes, optional developer signatures for authorship) is described in [security-model.md](./security-model.md).
